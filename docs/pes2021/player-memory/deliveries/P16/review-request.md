# P16 — Gate para o próximo passo

## Decisão independente

`ACCEPTED_WITH_PENDING`

A CT e o Lua foram aceitos como fontes de candidatos, não como verdade semântica. O layout `0x17C`, a existência dos offsets da CT e os AOBs desta versão estão sustentados. A direção fixa de vínculo implementada pelo Lua está refutada como regra geral.

## Trabalho autorizado a seguir

Somente leitura:

1. selecionar controles conhecidos na interface da ML;
2. confrontar salário anual, término do contrato e valor mostrado;
3. selecionar pelo menos um jogador emprestado **ao** clube e um emprestado **pelo** clube;
4. registrar os três pares `+0x12C`, `+0x160`, `+0x164` e a data `+0x16C` para cada controle;
5. repetir após reinício e redescoberta do endereço.

## Não autorizado

- executar ou instalar o hook Lua WORLD;
- ativar a CT;
- escrever qualquer campo do jogador;
- promover os CFGs WORLD a catálogo confirmado;
- implementar escrita de salário, contrato, mercado ou vínculo.

## Critérios para promoção futura

- dois controles de cada direção de empréstimo, quando disponíveis;
- coincidência exata entre interface e bytes em duas sessões;
- regra de direção sem contradição nos controles;
- escala monetária confirmada pela interface, não por plausibilidade;
- nova revisão Codex antes de uma API de leitura operacional.
